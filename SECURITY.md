# Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/superuserkalo/forwardpass-engine/security/advisories/new) for suspected vulnerabilities. Include the affected commit, a minimal reproduction, the expected access boundary and the impact you observed.

Do not put credentials, reader records or exploit details in a public issue. Use a local instance and synthetic data for reproduction. Publishing this code does not authorize testing against the hosted Forward Pass service or another operator's deployment.

Security fixes are made against the current default branch. There is no guaranteed response time or support commitment for older snapshots.
